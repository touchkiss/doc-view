# 设计

生成任务在已有后台read action内同时生成DocView列表与每项类名快照，作为同一结果回投EDT；用identity map避免对可变DocView做结构哈希。UI选择与导出只读快照，不读取PsiClass名字。Project在构造时缓存，避免UI反复经PSI对象取项目。关闭释放快照，过期任务不覆盖新结果；重载只保留一个本预览注册的选择监听器。

保留现有DocView模型、模板/JSON5/cURL、MCP/YApi、业务源码只读边界。导出快照保持精确文件名和文档列表。没有元数据的未完成加载不提供批量导出；匿名类的空名字使用文档标题或DocView作为保底。

回归使用真实后台加载/渲染/EDT切换，并通过代理PsiClass记录EDT名称读取次数，避免测试框架隐式锁掩盖问题。旧代码在列表切换/导出分别有2/1次EDT读取，两个测试均已明确失败。
